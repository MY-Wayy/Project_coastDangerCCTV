# 보고서·판넬 그림 재생성 (2026-11-02)

보고서·판넬에 쓰인 그림 4종을 제출 폴더(`테트라워치_분석데이터_소스코드/DatoryLab_trackB_2`)의 데이터로 다시 계산해 만든다.
원래 그림(10/18, 10/28 제작)은 만든 코드가 남아 있지 않았고, 아래 수치가 데이터와 달라 다시 그렸다.

| 그림 | 쓰인 곳 | 고친 값 |
|---|---|---|
| `fig00` 연도별 해양사고 발생 추이 | 판넬 분석배경, 종합보고서 | 기상 양호 92.5% → 92.6%, 용어 연안사고 → 해양사고 |
| `fig01` 해양사고 기상·해역 특성 | 판넬 분석배경 | 92.5% → 92.6%, 7.5% → 7.4%, 97.7% → 97.8%, 용어 |
| `fig07` 해안유형별 위험지수·사각지대 비율 | 판넬 분석결과, 최종보고서 <그림 4> | 완전 사각 35/34/185/251/39구간 → 34/32/177/229/28구간, v4 34구간 중 500m 내 CCTV 있음 24구간(70.6%) → 10구간(29.4%) |
| `trend` 해양사고 발생 추이 (건) | 최종보고서 <그림 1-0> | 2024년 전년 대비 +16.2% → +16.4%, 용어 |

예외: `fig01`의 "주요 사고 원인 상위 5개"(802·578·221·126·411건)는 원본 그림의 분류 기준(`occu_ty` 묶음)을 확인할 수 없어 원본 값을 그대로 두었다(`build_figures.py`의 `causes`).

## 실행

```bash
python build_figures.py      # pandas 필요, Chrome 설치 필요 → out/*.png
```

`templates/*.html`에 값을 채운 HTML을 `out/`에 쓰고, Chrome 헤드리스로 같은 크기의 PNG를 찍는다
(fig00 1600×1060, fig01·fig07 1600×900, trend 2222×1300). 글꼴은 Pretendard(설치되어 있지 않으면 Apple SD Gothic Neo).

## 판넬 「분석 결과」 패널 (2026-11-02 추가)

`build_panel_result.py <원본 판넬 .pptx>` → `out/panel_result.png` (2736×1530, 원본 1368×765의 2배 해상도).

고친 값은 fig07과 같다(완전 사각 34/32/177/229/28구간, 500m 내 CCTV 있음 10구간(29.4%)). 막대 값(2D 70.6%, 3D 25.1% 등)은 원본과 동일함을 확인했다.
