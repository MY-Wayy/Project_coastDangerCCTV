# 발표전 검증 — 30m 격자가 해안선 구간에 배정된 방식

질문: "위험지수는 격자에 매겨지는 값인가, 해안선에 매겨지는 값인가?"
답: **해안선 구간(1,832개)에 매겨지고, 격자는 가장 가까운 구간의 값을 물려받는다.** 이 폴더의 그림이 그 배정을 보여 준다.

## 그림

| 파일 | 내용 |
|---|---|
| `격자_구간배정_전체.png` | 부산 전체. 가시권 분석 격자 65,262개(30m, 해안선 양쪽 100m 띠, 합계 5,873.6ha)를 물려받은 위험지수 R로 칠함. 회색은 설치 제외 구간(섬·항만보안 등 368구간, 가중치 0)의 격자 |
| `격자_구간배정_확대_기장군.png` | 기장군 일대 확대. 왼쪽: 격자가 어느 구간에 배정됐는지(구간마다 다른 색, 점선은 구간별 100m 띠, 숫자는 구간 번호). 오른쪽: 같은 격자가 물려받은 R과 등급 |
| `격자_구간배정_확대_영도구.png` | 영도구 일대 확대, 구성은 위와 같음 |

## 배정 규칙 (코드 기준)

1. 해안선 구간마다 직선 조각별 ±100m 버퍼를 합쳐 띠를 만든다(`prepare_viewshed.py`의 `robust_buffer`).
2. 띠 안의 30m 격자에 구간 번호를 적는다. 두 구간의 띠가 겹치는 격자는 **더 가까운 구간**이 가져간다 → `outputs/viewshed/target_zone_index.tif`.
3. 신규 배치 계산에서 격자의 가중치 = 배정된 구간의 위험지수 R(`trackB_weights.csv`). 같은 구간의 격자는 모두 같은 값이다.
4. 확대 그림 왼쪽의 색은 이웃 구간을 구분하려고 번호 순서대로 10가지 색을 돌려 쓴 것이며, 색 자체에는 의미가 없다.
