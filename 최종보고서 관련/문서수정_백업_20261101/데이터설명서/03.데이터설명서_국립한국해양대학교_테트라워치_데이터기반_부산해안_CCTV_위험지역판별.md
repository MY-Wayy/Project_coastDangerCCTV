### 마. 민감도 분석 (sensitivity_fov_azimuth, sensitivity_height_range)

   - 1.1 sensitivity_fov_azimuth : 화각 미상 카메라 가정(3분류 기본 / 고정 60° / 고정 90°)별로 방위각 시나리오(해안 반대, 무작위 30회 평균·최소·최대, 해안 직시, 최적화) 커버율과 개선폭
   - 1.2 sensitivity_height_range : 설치 높이 ±2m, 가시거리 200/500m 변화에 따른 커버율과 완전 사각 구간 수

2. 가공 프로세스
   - 2.1 고정형 카메라 방위각을 시나리오별로 바꿔 가시권을 재계산, 무작위는 30회 반복 평균
   - 2.2 방위각 최적화는 15° 간격 탐욕 탐색 2회 반복 (`viewshed_sensitivity.py`)

### 바. 트랙 A 산출 CSV (해양기상·사고 기반 위험지수)

1. 데이터 설명
   - 1.1 1_관측소배정 : 구간별 구, 노출그룹(외해 1,036 / 내만 796), 배정 관측소(기장 620 / 오륙도 416 / 다대포 796)
   - 1.2 2_관측소별임계 : 관측소별 유효일수, 평균 유의파고, 지점별 임계(P85), 임계 초과일 비율, 풍속 임계
   - 1.3 3_해안유형별사고율 : 해안유형별 해안 길이, 사고 건수, km당 사고, 구간 수
   - 1.4 4_구간별위험지수 : 구간별 해안유형, 노출그룹, 관측소, 유형위험 T, 파랑노출 W, 위험지수 R, 위험등급(2~5), 반경 500m CCTV 지표
   - 1.5 5_CCTV설치후보 : 위험등급 4·5이면서 CCTV 공백인 설치후보 63구간

2. 가공 프로세스
   - 2.1 해안 구간을 외해·내만으로 나누고 가장 대표성이 있는 부이를 배정
   - 2.2 부이별 유의파고 P85 임계값으로 파랑노출 W 산출, 해안유형별 km당 사고율로 유형위험 T 산출
   - 2.3 위험지수 R = √(T × W), 등급 구간으로 나눠 위험등급 2~5 부여

### 사. 수동 제외 구간 및 가중치 (manual_site_exclusions, trackB_weights, station_thresholds, risk_weights_trackA)

1. 데이터 설명
   - 1.1 manual_site_exclusions : 위성사진으로 판독한 항만 보안·작업 구역, 거가대교 터널 구간 섬 등 설치 불가 구간 45건과 사유
   - 1.2 trackB_weights : 구간별 가중치 = 위험지수 R, 단 도서부(325구간)와 수동 제외 구간은 0 (설치 제외 합계 368구간)
   - 1.3 station_thresholds : 관측소별 파고 임계(m)와 풍속 임계(m/s)
   - 1.4 risk_weights_trackA : 트랙 A 설치후보 63구간의 위험지수 가중치

2. 가공 프로세스
   - 2.1 해안선 `GRP_ISL`=2(도서부)와 수동 제외 목록을 합쳐 설치 제외 마스크 생성 (`site_exclusions.py`)
   - 2.2 트랙 A 위험지수에 제외 마스크를 적용해 위험도 가중 배치용 가중치 파일 생성 (`build_trackD_dataset.py --weights-only`)

### 아. 신규 설치 후보 격자점 (new_site_candidates)

1. 데이터 설명 : 설치 가능한 육지 해안선에서 60m 이내이고 DSM 표고 1m 초과인 30m 격자를 90m(3칸) 간격으로 솎아 낸 후보점. 후보 ID와 지면 표고를 가진다.

2. 가공 프로세스
   - 2.1 설치 제외 구간을 뺀 해안선 60m 띠를 래스터화하고 제외 구간 띠는 제거
   - 2.2 표고 1m 초과 격자 중 행·열이 3의 배수인 격자만 선택 (`viewshed_new_sites.py`)

### 가. 신규 CCTV 배치 순위 (new_sites_ranked_trackB_weights, new_sites_ranked, new_sites_curve*, new_sites_top50_by_district*)

1. 데이터 설명
   - 1.1 new_sites_ranked_trackB_weights : 위험도 가중 배치 결과. 기준선(`original_360`: 3분류 기본 / `conservative_after_rotation`: 미상=고정 60° 방향 최적화 후)별로 순위 1~200, 후보 ID, 추가 가시 면적(ha), 추가 가중 면적, 주 구간 ID, 구·군, 닿는 구간 수, EPSG:5186 좌표. 최종 보고서의 상위 50곳은 `original_360` 기준선 1~50위이다.
   - 1.2 new_sites_ranked : 모든 구간 가중치를 1로 둔 균등 배치 결과 (비교용)
   - 1.3 new_sites_curve* : 신규 0·10·20·50·100·200대일 때의 커버율, 가중 커버율, 추가 면적, 완전 사각 구간 수
   - 1.4 new_sites_top50_by_district* : 상위 50대의 구·군별 대수

2. 가공 프로세스
   - 2.1 기존 카메라 가시권 합집합(`V_base`)을 기준으로, 아직 덮이지 않은 대상구역 격자의 가중 면적을 가장 많이 늘리는 후보를 차례로 고르는 지연 탐욕(Lazy Greedy) 알고리즘 적용 (신규 카메라: PTZ 360°, 높이 8m, 가시거리 300m)
   - 2.2 가중치 파일(`trackB_weights.csv`)을 넣으면 위험도 가중, 넣지 않으면 균등 배치 (`viewshed_new_sites.py --n 200 [--weights]`)
   - 2.3 N대 추가 시마다 누적 커버율을 기록하여 곡선 생성

### 나. 최종 상위 50개 후보지 촬영방향 3분류 (top50_sites_direction_classified)

   - 2.1 연안사고 좌표(EPSG:3857)를 EPSG:5186으로 변환하고 후보지 반경 500m 버퍼 안의 사고를 집계
   - 2.2 분류 규칙 적용: 사고 ≥ 3건 또는 (중대사고 ≥ 2건이면서 방파제·암벽·테트라포드·갯바위·인공 해안) → ①, 사고 1~2건 또는 항포구·해수욕장 → ②, 그 외 → ③ (`plot_viewshed_maps.py`)
